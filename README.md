 🎬 Netflix Content Strategy Analysis Dashboard

📌 Overview
The **Netflix Content Strategy Analysis Dashboard** is an interactive data visualization project built using **Python, Streamlit, Pandas, and Plotly**. It analyzes Netflix content to uncover trends in viewership, content types, languages, release patterns, and strategic insights.

The dashboard enables users to explore the dataset through interactive filters and visualizations, making it easier to understand audience preferences and content performance.

---

🚀 Features

- 📊 Interactive KPI Cards
- 🎥 Content Type Analysis
- 🌍 Language-wise Viewership Analysis
- 📈 Monthly & Yearly Viewership Trends
- 🍂 Seasonal Performance Analysis
- 📅 Release Day Analysis
- 🏆 Top Viewed Titles
- 🔍 Search and Filter Functionality
- 📥 Download Filtered Data
- 💡 Strategic Business Recommendations

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Netflix-Content-Dashboard.git
```

Move into the project folder:

```bash
cd Netflix-Content-Dashboard
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run dashboard_app.py
```
